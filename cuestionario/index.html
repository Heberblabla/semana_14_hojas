Cuestionario resuelto

Bootstrap es un framework de código abierto para crear interfaces web responsivas. Nació en Twitter y se publicó como proyecto abierto en 2011. Incluye hojas de estilo CSS (rejilla, tipografía, utilidades), componentes listos (navbar, card, modal, formularios, alert, badge…) y componentes JavaScript (bundle con Popper). La versión 5.3 ya no depende de jQuery y ofrece variables CSS y modo oscuro.

Mobile-first significa que los estilos base se escriben para pantallas pequeñas y luego se amplían a pantallas mayores mediante breakpoints (sm, md, lg, xl, xxl) con prefijos como col-md-6. Así el diseño parte de lo esencial y crece, en lugar de reducirse.

La rejilla usa Flexbox y divide cada row en 12 columnas; cada col-* indica cuántas ocupa, dentro de un container que limita y centra el contenido. Si las columnas de una fila suman más de 12, las sobrantes pasan a la línea siguiente.

Interpretación de col-12 col-md-6 col-lg-4:

  • Móvil (< 768 px): col-12 → 12/12 = 1 columna por fila.
  • Tableta (≥ 768 px): col-md-6 → 6/12 = 2 columnas por fila.
  • Laptop (≥ 992 px): col-lg-4 → 4/12 = 3 columnas por fila.

Contiene el JavaScript de los componentes interactivos de Bootstrap e incluye Popper (posicionamiento de menús desplegables, tooltips y popovers). Lee atributos como data-bs-toggle y data-bs-target. Sin él dejan de funcionar, por ejemplo, el menú hamburguesa colapsable de la navbar (Ejercicio 1), los modal, los dropdown, el carrusel y el offcanvas. Si solo se usan rejilla, tarjetas y botones, basta el CSS.

Ventajas: (1) rapidez, con componentes y rejilla listos; (2) diseño responsivo mobile-first incorporado; (3) documentación extensa, comunidad grande y consistencia entre páginas y equipos.

Limitaciones: (1) aspecto reconocible si no se personaliza; (2) peso, porque se descargan estilos no usados si no se compila una versión propia (otras: marcado extenso, especificidad al sobrescribir).

Cómo diferenciarse: personalizar con variables --bs-* o Sass ($primary, $border-radius, tipografía), definir una paleta y fuentes propias, añadir CSS propio cargado después de Bootstrap y compilar solo los módulos necesarios.
